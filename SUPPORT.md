# Support

Thanks for using the **Path of Exile 2 Filter** extension!

## Reporting bugs and requesting features

Please open an issue on GitHub:

- Bugs and feature requests: https://github.com/thmsndk/vscode.poe2-filter/issues

When reporting a bug, it helps to include:

- A small filter snippet that reproduces the problem
- What you expected to happen and what actually happened
- Your VS Code version and operating system

## Questions

For general questions, open a [GitHub issue](https://github.com/thmsndk/vscode.poe2-filter/issues) or start a discussion on the repository.
